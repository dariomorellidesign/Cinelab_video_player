# Support link setup

The project can show a voluntary-support button in the GitHub sidebar and in the README.

1. Create a public profile at either [Ko-fi](https://ko-fi.com) or [Buy Me a Coffee](https://www.buymeacoffee.com).
2. Send the public profile URL to the maintainer working on the release.
3. Add the profile to `.github/FUNDING.yml` and replace the README support placeholder with the same link.

Use only the public creator URL. Never place API keys, login credentials or payment details in this repository.
